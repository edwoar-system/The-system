# The System

A personal "life as a game" app in the style of Solo Leveling: quests, XP, levels, stats and coins.
Coins unlock blocked apps on the iPhone (Screen Time API).

- Website (test version): https://edwoar-system.github.io/The-system/
- Built with Expo (web + iOS) and Firebase (Auth + Firestore).
- Every push to `main` rebuilds and deploys the website automatically.

## Building in rooms

The app is built room by room. A room is built, tested, and only then finished.

| Room | Content |
| --- | --- |
| 0 | Foundation: login, database, website, empty iPhone app |
| 1 | Blocking apps and unlocking with coins |
| 2 | Quests and economy (design v0.1: Status, quest board, level up) |
| 3 | Stats and ranks |
| 4 | Body |
| 5 | Health |
| 6 | School |
| 7 | Learning |
| 8 | Life |
| 9 | Help |
